# フィッシング見抜きトレーニング（phishing-quiz）

大学生がフィッシング詐欺・なりすましメールを見抜く力をつけるための学習ゲームです。
PBL「生活環境と情報」の授業用に作った最小版（MVP）です。

- HTML / CSS / JavaScript だけで動く静的サイトです（ビルド不要・サーバー代ゼロ）。
- 外部API・データベース・ログイン・アクセス解析は使いません。**個人情報は一切集めません。**
- スコアや進み具合は、使っている端末のブラウザ（localStorage）にだけ保存します。保存できない環境でも、そのプレイ中は動きます。
- 偽メールの見本は**すべて架空**です。大学名は「○○大学」「OMU」、URLやメールアドレスは予約ドメイン（`example.com` / `example.jp` / `example.net`）だけを使っています。見本の中のリンクは押してもどこにも移動しません。

## ファイル構成

| ファイル | 中身 | 班員が編集する？ |
|---|---|---|
| `index.html` | 画面の骨組み | ほぼ不要 |
| `style.css` | 見た目（色・文字サイズ・ダークモード） | ほぼ不要 |
| `app.js` | ゲームの動き、ボタンなどの文言（3言語） | ほぼ不要 |
| `questions.json` | **問題データ** | **ここを編集します** |
| `README.md` | この説明書 | 必要に応じて |

## ゲームの流れ

1. スタート画面（説明・言語・文字サイズ・画面の色の切り替え）
2. 事前テスト 3問（判定だけ。解説なし）
3. 本編 5問
   1. メール／SMS／チャット（LINE風）の模擬画面が表示される
   2. 「送信元を確認」か「リンク先を確認」を開くまで判定できない（確認すると、実際のアドレスやリンク先URLが見える）
   3. 「本物だと思う」か「あやしい」を選ぶ
   4. 「あやしい」を選んだら、画面の中であやしい箇所をタップして選ぶ
   5. 正誤・見抜くポイント・実際に届いたときの正しい行動が表示される
4. 事後テスト 3問（判定だけ）
5. 結果画面（正答率、事前→事後の変化、カテゴリ別の習熟度、バッジ、「迷ったときの3つの行動」、結果のコピー）

結果は「結果をコピー」でテキストとしてコピーし、学生自身が班のGoogleフォームに貼り付けて提出します。アプリが送信することはありません。

## 1. パソコンで開いて試す（ローカルでの開き方）

> ⚠ `index.html` をダブルクリックして開くと、ブラウザの安全のための制限で `questions.json` が読み込めず、「問題を読み込めませんでした」と表示されます。下のどちらかの方法で開いてください。

### 方法A：Visual Studio Code の「Live Server」を使う（おすすめ）

1. [Visual Studio Code](https://code.visualstudio.com/) をインストールします。
2. 左の「拡張機能」（四角が4つのアイコン）で **Live Server** を検索してインストールします。
3. 「ファイル」→「フォルダーを開く」で、このフォルダーを開きます。
4. `index.html` を右クリック →「Open with Live Server」を選ぶと、ブラウザで開きます。
5. ファイルを保存すると、ブラウザが自動で更新されます。

### 方法B：Python を使う

Python が入っているパソコンなら、このフォルダーでターミナル（Windowsは「コマンドプロンプト」）を開き、次を入力します。

```
python -m http.server 8000
```

（`python` で動かない場合は `python3` や `py` を試してください）
ブラウザで <http://localhost:8000/> を開きます。終わるときはターミナルで `Ctrl + C` を押します。

## 2. GitHub Pages でインターネットに公開する

GitHub Pages を使うと、無料でサイトを公開できます。

1. GitHub でこのリポジトリ（`phishing-quiz`）を開きます。
2. 上のメニューの **Settings**（歯車）をクリックします。
3. 左のメニューから **Pages** をクリックします。
4. 「Build and deployment」の **Source** で **Deploy from a branch** を選びます。
5. **Branch** で `main`、フォルダーで `/ (root)` を選び、**Save** を押します。
6. 1〜2分待ってページを再読み込みすると、上に
   `Your site is live at https://（ユーザー名）.github.io/phishing-quiz/` と表示されます。このURLを学生に配ります。

※ リポジトリが **Public（公開）** になっている必要があります（無料プランの場合）。
※ `main` に変更を push（またはGitHub上で編集して Commit）すると、数分で公開中のサイトにも反映されます。反映されないときは、ブラウザで強制再読み込み（Windows: `Ctrl + F5`、Mac: `Cmd + Shift + R`）をしてください。

### GitHub上で直接 questions.json を編集する方法

パソコンに何も入れなくても、GitHub のサイト上で編集できます。

1. リポジトリのファイル一覧で `questions.json` をクリックします。
2. 右上の鉛筆アイコン（Edit this file）をクリックします。
3. 編集したら、右上の **Commit changes...** を押し、変更内容を一言書いて **Commit changes** を押します。

## 3. questions.json に問題を追加・修正する

### 全体の形

```json
{
  "preTest":  ["事前テストに使う問題のid", "...", "..."],
  "postTest": ["事後テストに使う問題のid", "...", "..."],
  "categories": {
    "university": { "ja": "大学をかたる", "easy": "大学の ふりを する", "en": "..." },
    "life":       { "ja": "生活", ... },
    "student":    { "ja": "学生を狙う", ... }
  },
  "questions": [ { 1問目 }, { 2問目 }, ... ]
}
```

- `preTest` と `postTest` に書いた問題は、事前・事後テストで使われます。それ以外の問題から、本編の5問がランダムに選ばれます（まだ解いていない問題や、苦手なカテゴリが優先されます）。
- 事前と事後で点数を比べるので、2つのテストは**難しさとカテゴリをそろえて**ください（いまは「大学の偽メール・生活の偽メール・大学の本物の連絡」を1問ずつ）。

### 1問の書き方（例）

```json
{
  "id": "univ-password-01",
  "category": "university",
  "channel": "email",
  "isPhishing": true,
  "time": "8:12",
  "sender": {
    "name": { "ja": "OMU 情報システム課" },
    "address": "it-support@omu-security.example.com"
  },
  "subject": {
    "ja": "【重要・至急】パスワード再設定のお願い",
    "easy": "【大事・いそいで】パスワードを 新しく してください"
  },
  "body": {
    "ja": "{{greet|学生各位}}\n\n{{urgency|本日17時までに}}下記から再設定してください。\n\n[[link1]]",
    "easy": "{{greet|学生の みなさんへ}}\n\n{{urgency|今日の 17時までに}} 下の ページで パスワードを 新しく して ください。\n\n[[link1]]"
  },
  "links": [
    { "id": "link1", "text": "https://omu.example.jp/password-reset", "url": "https://omu-security.example.com/login" }
  ],
  "suspiciousParts": [
    { "id": "sender",  "reason": { "ja": "大学のドメインではありません。", "easy": "大学の アドレスでは ありません。" } },
    { "id": "urgency", "reason": { "ja": "短い期限で急がせています。", "easy": "いそがせて います。" } },
    { "id": "link1",   "reason": { "ja": "表示と実際のリンク先が違います。", "easy": "見えて いる URLと 本当の 行き先が ちがいます。" } }
  ],
  "explanation": { "ja": "解説の文", "easy": "やさしい日本語の解説" },
  "action": { "ja": "実際に届いたときの正しい行動", "easy": "やさしい日本語の行動" }
}
```

### 各項目の意味

| 項目 | 意味 | 書き方 |
|---|---|---|
| `id` | 問題の名前（重複しないもの） | 半角英数字とハイフン。例：`life-delivery-02` |
| `category` | カテゴリ | `university`（大学をかたる）／`life`（生活）／`student`（学生を狙う） |
| `channel` | 画面の種類 | `email`（メール）／`sms`（SMS）／`line`（チャット・LINE風） |
| `isPhishing` | 偽物かどうか | 偽物なら `true`、本物なら `false` |
| `time` | 画面に出る受信時刻（なくてもよい） | 例：`"8:12"` |
| `sender.name` | 画面に表示される差出人の名前 | 言語ごとに書く |
| `sender.address` | 「送信元を確認」で見える本当の送信元 | 文字だけ、または言語ごとに書く |
| `subject` | 件名（メールのときだけ） | 言語ごとに書く |
| `body` | 本文 | 言語ごとに書く（下の「本文の書き方」を参照） |
| `links` | 本文中のリンク | `id`、表示される文字 `text`、本当の行き先 `url` |
| `suspiciousParts` | 指摘すべきあやしい箇所と理由 | 本物の問題は `[]`（空っぽ） |
| `explanation` | 解説 | 言語ごとに書く |
| `action` | 実際に届いたときの正しい行動 | 言語ごとに書く |

### 言語の書き方

文章は `{ "ja": "ふつうの日本語", "easy": "やさしい日本語", "en": "English" }` の形で書きます。

- `ja` は必ず書いてください。`easy` や `en` がない場合は、`ja` の文が表示されます。
- 1種類しか必要ない文（URLなど）は、`"text": "https://..."` のようにそのまま書いても大丈夫です。

### 本文の書き方（あやしい箇所の印のつけ方）

- 改行は `\n`、空行は `\n\n` と書きます。SMSとチャットでは、空行ごとに吹き出しが分かれます。
- **タップして選べる箇所**は `{{名前|文字}}` と書きます。例：`{{urgency|本日17時までに}}`
  - `名前` は半角英数字。`suspiciousParts` の `id` と合わせます。
  - あやしくない箇所にも印をつけておくと、「全部選べば正解」にならない練習になります（例：`{{greet|学生各位}}`）。
- **リンク**は本文中に `[[link1]]` と書き、`links` に同じ `id` で中身を書きます。
- 差出人（`sender`）と件名（`subject`）、各リンクは、印をつけなくても自動で選べる箇所になります。`suspiciousParts` の `id` に `"sender"`、`"subject"`、`"link1"` のように書けます。
- `ja` と `easy` では、同じ印（`{{名前|…}}`、`[[link1]]`）を同じ数だけ使ってください。

### 安全のための決まり（必ず守る）

- 実在する大学・企業のロゴ、公式デザイン、実在のドメインやURLは**使わない**。
- URLとメールアドレスは `example.com`／`example.jp`／`example.net` か、その前に文字をつけたもの（例：`omu-pay.example.com`）だけを使う。
- このゲームでは、**大学の正しいドメインは `omu.example.jp`** という設定です（Moodleは `lms.omu.example.jp`）。本物の問題ではこれを使ってください。
- 電話番号は `080-XXXX-1234` のように一部を伏せて書く。
- 大学のインシデントについては「流出しました」と断定せず、「流出の恐れ」と書く（偽メールが断定している、という設定の文は除きます）。

### 編集したあとの確認

- JSONは、カンマ `,` の付け忘れ・付けすぎや、`"` の閉じ忘れがあると読み込めなくなります。うまく動かないときは、[JSONLint](https://jsonlint.com/) などに貼り付けて間違いを探してください。
- 問題を読み込めないと、画面に「問題を読み込めませんでした」と表示されます。
- 追加したら、ローカル（上の「1.」）で実際に解いて確かめてから公開しましょう。

## ボタンなどの文言を変えたいとき

ボタンや説明文などの文言は `app.js` の上のほうにある `UI` の中に、`ja`（ふつうの日本語）・`easy`（やさしい日本語）・`en`（English）の順で書いてあります。`'…'` の中の文字だけを書き換えてください。

## 記録（localStorage）について

- スコア、確認ステップの使用回数、カテゴリ別の正答数、バッジ、設定を、ブラウザの localStorage（キー名 `phishingQuiz.v1`）に保存します。
- 個人を特定する情報は保存しません。外部にも送信しません。
- 「設定」→「記録を消去」で消せます。
- プライベートブラウズなどで保存できないときは、画面にその旨を表示し、そのプレイ中だけ記録します。

## アクセシビリティ

- スマホ優先のレスポンシブデザイン（幅320pxでも横スクロールなし）
- ふつうの日本語／やさしい日本語／English の切り替え
- 文字サイズ（小・中・大）、ライト／ダーク／端末に合わせる の切り替え
- 正誤やバッジは色だけでなく、アイコン（✔ ✖ ⚠ 🔒）と文字でも表示
- キーボード操作（Tab・Enter・Space・矢印キー）とスクリーンリーダー（見出しへのフォーカス移動、`aria-pressed`・`aria-expanded`・読み上げ通知など）に対応
